这一步是**选读**：前六步走完，你已经能从零把 Hermes 跑起来、接上自己的模型、用 CLI 检查状态，并完成一次真实的工具调用。接下来往哪走，官方给了按经验水平和按使用场景两张地图。

### 按经验水平

| 水平 | 目标 | 预计时间 |
|---|---|---|
| **初级** | 快速上手，进行基本对话，使用内置工具 | 约 1 小时 |
| **中级** | 搭建消息机器人，使用记忆、cron、技能等高级功能 | 约 2–3 小时 |
| **高级** | 构建自定义工具、创建技能、训练模型、参与贡献 | 约 4–6 小时 |

### 按使用场景

官方列了六条场景线，每条都给出推荐阅读顺序：

1. **CLI 编程助手** — 安装 → 快速入门 → CLI 用法 → 代码执行 → 上下文文件 → 技巧
2. **Telegram / Discord 机器人** — 安装 → 配置 → 消息概览 → Telegram / Discord 配置 → 语音模式 → 安全
3. **任务自动化** — 快速入门 → Cron 调度 → 批处理 → 委派 → Hooks
4. **自定义工具 / 技能** — 插件 → 构建插件 → 工具概览 → 技能概览 → MCP → 架构
5. **训练模型** — 快速入门 → 配置 → 强化学习训练 → Provider 路由 → 架构
6. **当作 Python 库使用** — 安装 → 快速入门 → Python 库指南 → 架构 → 工具 → 会话

### 主要功能一览

不确定有哪些能力时，可以用这张表定位：

| 功能 | 说明 |
|---|---|
| **工具** | 内置工具：文件 I/O、搜索、Shell 等 |
| **技能** | 可安装的技能包，扩展新能力 |
| **记忆** | 跨会话的持久化记忆 |
| **上下文文件** | 把文件与目录直接传进对话 |
| **MCP** | 通过模型上下文协议连接外部工具服务器 |
| **Cron** | 调度周期性 agent 任务 |
| **委派** | 生成子 Agent 并行处理工作 |
| **浏览器** | 网页浏览与抓取 |
| **Hooks** | 事件驱动的回调与中间件 |
| **Provider 路由** | 在多个 provider 之间路由请求 |

</Callout>
